# Changelog

### Added
- Initial release
- GUI for managing Android applications via ADB
- Support for viewing all installed applications
- Enable/disable applications
- Uninstall applications (including system apps)
- Install APK files
- Batch disable operations
- Dark/Light theme support
- Russian and English language support
- Integration with Universal Android Debloater lists
- .deb and .rpm package support

### Technical
- Modular architecture with separate UI, core, and utils
- Proper error handling and validation
- Threaded ADB operations
- Theme system
- Internationalization support
